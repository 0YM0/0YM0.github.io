Selected Research

Selected research projects in visual perception, remote sensing, and multimodal scene understanding.

Interactive Vision System · 2025–2026

Training-Free Interactive Auto-Labeling for Remote Sensing Imagery

An interactive annotation framework integrating open-vocabulary segmentation and promptable foundation models. The system enables users to specify novel objects with text or visual exemplars and generates editable polygon annotations without task-specific retraining.

Semantic Segmentation · 2024–2026

Large-Scale Barn Detection from High-Resolution Satellite Imagery

A large-scale semantic segmentation pipeline for detecting livestock facilities from high-resolution satellite imagery. The work covers data construction, preprocessing of multi-terabyte geospatial imagery, model development, post-processing, and geographic information extraction.

Semantic Segmentation Satellite Imagery PyTorch MMSegmentation

Multimodal Scene Understanding · 2025–2026

Context-Aware Visual Perception with Geospatial Graphs

Exploring how structured geographic context can complement RGB imagery for visual recognition. Land-cover relationships are modeled as graphs and fused with visual representations to improve semantic segmentation under ambiguous visual appearance.
